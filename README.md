# focus-board

Agent skill for maintaining a personal, Logseq-backed **Focus Board** repository in git — shared between a human and their AI agents across work or personal life.

## Install

```bash
git clone https://github.com/Jopie64/focus-board-agent-skill ~/.agents/skills/focus-board
```

## What's inside

- `SKILL.md` — minimal conventions for reading, updating, and triaging a Focus Board.
- `references/bootstrap.md` — instructions for initializing a new Focus Board repository.
